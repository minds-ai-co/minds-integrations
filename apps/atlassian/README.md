# Minds for Atlassian

## Product workflow

- Jira issue action: create a reviewable research plan from an epic,
  requirement, or selected description.
- Confluence content action: plan a study from a product brief.
- Result panel: attach a durable summary link and selected aggregate findings
  to the originating issue or page.

## Publication gate

Build as a Forge app. Use a first-party Minds OAuth connection, minimum Jira or
Confluence scopes, explicit external fetch permissions, and plan-before-run.
Complete Atlassian vendor, privacy, support, security, listing, and review
requirements before Marketplace submission.
