# Minds for Google Sheets

The Apps Script add-on reads questions from the first column of the selected
range, asks an existing Minds Group, and writes results into the adjacent
column. It shows a specific confirmation with the number of questions before
any paid or consequential call.

The API key is stored in Apps Script user properties, never in a cell or the
script source. A public Workspace Marketplace release still requires a Google
Cloud project, OAuth review if requested, listing assets, and Google review.
