# Minds Panel Analytics for Looker Studio

This community connector loads the live analytics object for an existing Minds
Panel and exposes each top-level metric as a dashboard row. It uses Looker
Studio key authentication and Apps Script user properties.

Gallery publication requires an Apps Script deployment, review, support and
privacy URLs, a report template, and a public source repository. No secret
belongs in source code.

Public reviewer and user documentation:
<https://getminds.ai/guide/looker-studio>

The connector manifest uses the pending `MINDS_PANEL_ANALYTICS` data source.
Google data registry PR: <https://github.com/googledatastudio/ds-data-registry/pull/1285>
