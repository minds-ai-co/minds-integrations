# Support

For account, billing, API-key, or Minds product support, use
[Minds support](https://getminds.ai/contact).

For a reproducible defect in this extension, open an issue in the
[Minds integrations repository](https://github.com/minds-ai-co/minds-integrations/issues)
with the VS Code version, extension version, steps to reproduce, and sanitized
error text. Never include an API key or private research material.
