# Dataset discovery

Minds study pages already emit server-rendered schema.org `Dataset` metadata.
Google Dataset Search is discovery, not a submission portal.

The planned quarterly benchmark should add downloads only when a real,
reviewed aggregate dataset exists. At publication it needs a stable canonical
page, descriptive name and description, creator, version, license, provenance,
`DataDownload` entries, a DOI identifier, and unambiguous `sameAs` links to
matching Zenodo, Hugging Face, and Kaggle records.

Do not publish illustrative study content as a downloadable benchmark dataset.
